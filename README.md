# BeautyMind AI — Streamlit deployment

This repository contains the Streamlit version of the BeautyMind AI research prototype.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

The application uses the trained models in `models/` and the SQLite database in `db/`.

## Deploy

Deploy `app.py` from this GitHub repository using Streamlit Community Cloud.
